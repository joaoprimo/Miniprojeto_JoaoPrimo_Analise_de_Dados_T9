# Pasta `dados/`

Aqui está a base **Varejo** do Kaggle, já incluída no repositório (`Base_Varejo.zip`, 3,9 MB):
<https://www.kaggle.com/datasets/namespaiva/base-varejo/data>

- O script abre o `.zip` sozinho: **não precisa descompactar** nem baixar nada.
- Para usar outra cópia da base, troque o arquivo desta pasta. Nomes aceitos: `Base_Varejo.zip`,
  `Base Varejo.csv`, `Base_Varejo.csv`, `Varejo.csv` (ou qualquer `.csv`/`.zip` com "varejo" no nome).
- O script também procura o arquivo na mesma pasta do `analise_varejo.py`.
